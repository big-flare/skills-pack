Resolve the decisions above

Fix any conflicting fact at its source (your product page or feed), or tell your copywriter which version is right. The new descriptions leave those facts out until then.

Upload {{TSV_NAME}} to Google Merchant Center

  1. Open Settings (the gear icon) → Add-ons and turn on Advanced data source management. You only do this once. Without it, the Supplemental sources tab doesn't appear.
  2. Go to Settings → Data sources, open the Supplemental sources tab and select Add supplemental product data.
  3. Choose A file and follow the prompts: give the source the file's exact name, extension included ({{TSV_NAME}}), and upload the file. If it asks for a feed label and language, use the same ones as your main product feed.
  4. Select the primary data source your products come from, then Create data source.
  5. Allow up to a day for processing, then open the new source and check it processed without errors. Rows whose id doesn't match a product in your main feed are ignored, so if a description hasn't changed, check its ID first.

Rows match your products on id, so the new text replaces the description in Shopping without touching your store or your main feed. The file also carries a structured_description column marked as AI-generated, because Google's rules ask for AI-written descriptions to be declared that way. To undo it, delete the supplemental source and the original descriptions come back.

Menu names checked against Google's Merchant Center help in November 2026. If they have moved, search Merchant Center Help for “supplemental data source”.

A/B test on a handful of top sellers

Duplicate a few top-selling products with new item IDs, changing nothing else (the links stay the same). Give only the duplicates the new descriptions, and run originals and duplicates in the same campaign.

Compare after 4–6 weeks, keep the winner

Compare impressions, clicks, revenue and ROAS for each original against its duplicate. Roll the winning descriptions out to the rest of the catalogue, and remove the losing copies.
