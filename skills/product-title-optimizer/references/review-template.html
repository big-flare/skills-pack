What to do next

Read the titles, change anything you want, then upload. Nothing changes in your store, your main feed or Google until you upload the file yourself.

Review and edit in {{XLSX_NAME}}

The Titles tab lists every product with its original and new title. Edit any title in the New title column. The Characters column updates as you type and turns red outside 130–150. Then give the saved file back to Claude and say “apply my edits”: it re-checks every title and rebuilds the feed file. The Research and Keywords tabs show what each title was built from.

Upload {{TSV_NAME}} to Google Merchant Center

  1. Open Settings (the gear icon) → Add-ons and turn on Advanced data source management. You only do this once. Without it, the Supplemental sources tab doesn't appear.
  2. Go to Settings → Data sources, open the Supplemental sources tab and select Add supplemental product data.
  3. Choose A file and follow the prompts: give the source the file's exact name, extension included ({{TSV_NAME}}), and upload the file. If it asks for a feed label and language, use the same ones as your main product feed.
  4. Select the primary data source your products come from, then Create data source.
  5. Allow up to a day for processing, then open the new source and check it processed without errors. Rows whose id doesn't match a product in your main feed are ignored, so if a title hasn't changed, check its ID first.

Rows match your products on id, so the new titles replace the old ones in Shopping without touching your store or your main feed. The file also carries a structured_title column marked as AI-generated, because Google's rules ask for AI-written titles to be declared that way. To undo it, delete the supplemental source and the original titles come back.

Menu names checked against Google's Merchant Center help in November 2026. If they have moved, search Merchant Center Help for “supplemental data source”.

Want proof first? Test on a few top sellers

Duplicate a few top-selling products with new item IDs, changing nothing else (the links stay the same). Give only the duplicates the new titles, run originals and duplicates in the same campaign for 4–6 weeks, then compare impressions, clicks, revenue and ROAS by item ID and keep the winner.

Look again in 4–6 weeks

Check which searches your products now show for, and rerun this every few months, or whenever you add products: search behaviour changes, and new search terms are new title material.
